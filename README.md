# RAG Document Q&A Assistant

Upload documents, ask questions, and get answers with source citations. Runs fully locally using Ollama, with no API keys needed.

## Features

- Hybrid search (BM25 + vector search) for accurate retrieval
- Supports PDF, DOCX, TXT, MD, CSV and XLSX files
- Answers include sources (page, section or row range)
- FastAPI backend with a Streamlit web UI

## Tech Stack

FastAPI · Streamlit · ChromaDB · Ollama (Qwen + nomic-embed-text) · PyMuPDF

## Setup

**Prerequisites:** Python 3.11+ and [Ollama](https://ollama.com)

```bash
ollama pull qwen3:4b-instruct
ollama pull nomic-embed-text:latest

python -m venv env
env\Scripts\activate          # macOS/Linux: source env/bin/activate
pip install -r requirements.txt
```

## Run

```bash
# Terminal 1 - backend
python -m backend.app.main

# Terminal 2 - frontend
python -m streamlit run frontend/app.py
```

Open http://localhost:8501 (API docs at http://localhost:8000/docs).

## Results

All numbers come from local models (`qwen3:4b-instruct` for answers, `nomic-embed-text` for embeddings).

- **Tests:** 225 passing (pytest), 4 skipped (optional PDF fixture tests)

**Live evaluation on real documents** (`python -m evaluation.run_eval`)

A 47-question golden set over a corpus of 8 real PDFs (about 1,800 passages): four research papers (Attention Is All You Need, BERT, Llama 2, RAG), India's Digital Personal Data Protection Act 2023, the NIST AI Risk Management Framework, and two machine-learning textbook modules. There are 39 answerable questions and 8 that the documents cannot answer. Questions were generated by an LLM, filtered by code, and curated by hand. Answers were graded by an LLM judge (the same model that answers).

| Metric | Result |
|---|---|
| Answer accuracy | 85% (33/39) |
| Answer accuracy when the source passage was retrieved | 91% |
| Recall@5 (source passage in top 5) | 85% (33/39) |
| MRR | 0.58 |
| Correct refusals on unanswerable questions | 100% (8/8) |
| Latency per answer (local hardware) | avg 14 s, p95 24 s |

Notes: one of the six misses was a transient Ollama server error, and the others include a retrieval miss on a very common legal term, an abstention, and answers a stricter or more lenient judge might grade differently. With 39 questions the true accuracy is roughly 70% to 93%.

**Retrieval benchmark on synthetic documents** (`tests/test_benchmark_retrieval.py`)

| Metric (14 answerable questions) | Score |
|---|---|
| Recall@5 | 93% (13/14) |
| Recall@3 | 79% |
| Recall@1 | 32% |
| MRR | 0.55 |
